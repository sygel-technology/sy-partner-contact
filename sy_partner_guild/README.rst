This module allows you to define guilds and assign them to partners.
Guilds are propagated from the commercial entity to its contacts.

Usage
=====

To use this module:

1. Go to **Contacts > Configuration > Guilds > Guilds**.
2. Create the guilds that you want to use and optionally assign a color
   to each one.
3. Go to **Contacts** and open a company.
4. Select the applicable guilds in the **Guilds** field.

The guilds assigned to a company are automatically propagated to its
contacts.
