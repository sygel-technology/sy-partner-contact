========================================
Partner Private Information Autocomplete
========================================
This module autocomplete private information tab in partners.


Installation
============
To install this module, you need to:

Just install.


Configuration
=============

To configure this module, you need to:

#. Just install.


Usage
=====

To use this module, you need to:

#. When changing the value of any of the client's address, phone, mobile or email fields, 
  if the private field does not contain a value, that value will be added.
