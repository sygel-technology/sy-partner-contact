This module allows you to store the old account numbers of customers and
vendors.

Usage
=====

To use this module, you need to:

1. Go to the Contacts module
2. Select or create a new contact
3. Go to the Invoicing tab
4. Fill in the fields 'Old customer account number' or/and 'Old vendor
   account number'.
